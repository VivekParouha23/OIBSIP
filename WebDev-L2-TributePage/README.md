# Tribute Page: Dr. A. P. J. Abdul Kalam

A responsive tribute page with biography, milestone timeline and a quote block. Before submitting, download a royalty-free portrait from Wikimedia Commons, save it as kalam.jpg in this folder, and verify the quote's source.

## Run it
Open index.html in a browser.

## Tech
HTML5, CSS3, Google Fonts (Playfair Display + Lato).
