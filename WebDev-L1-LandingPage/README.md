# Landing Page: Chai Ghar

A responsive landing page for a fictional chai subscription brand. It has a sticky navbar, hero with call-to-action, features, story and reviews sections, and a footer.

## Run it
Open `index.html` in any browser. No install needed.

## Tech
HTML5, CSS3 (Flexbox, Grid). No JavaScript.
