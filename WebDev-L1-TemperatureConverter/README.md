# Temperature Converter

Converts a value between Celsius, Fahrenheit and Kelvin and shows all three results. It rejects non-numeric input and values below absolute zero.

## Run it
Open `index.html` in any browser. No install needed.

## Tech
HTML5, CSS3, Vanilla JavaScript.
