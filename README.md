# Tribute Page: Manoj Parouha

A responsive tribute to my father, a farmer and the hardest worker I know. It has a biography section, a "what he taught me" list, and a quote block.

## Before you publish
- Save a photo of him as `papa.jpg` in this folder (use a photo of your own family).
- Edit the paragraphs in `index.html` and add real details: village, crops, years of farming, a story you remember.
- Change the quote to something he really says, if you like.

## Run it
Open `index.html` in a browser.

## Tech
HTML5, CSS3, Google Fonts (DM Serif Display + Public Sans).
