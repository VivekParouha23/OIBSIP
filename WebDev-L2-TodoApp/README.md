# To-Do Web App

Add, edit, complete and delete tasks, with separate Pending and Completed lists, counts, timestamps, empty states and localStorage persistence.

## Run it
Open index.html in a browser.

## Tech
HTML5, CSS3, Vanilla JavaScript.
