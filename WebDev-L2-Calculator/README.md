# Calculator

Browser calculator with + − × ÷, decimals, clear, backspace and divide-by-zero handling. It does not use eval(). Operations chain left to right, so 5 + 3 × 2 gives 16 (like a basic pocket calculator).

## Run it
Open index.html in a browser.

## Tech
HTML5, CSS Grid, Vanilla JavaScript (addEventListener, no inline onclick).
